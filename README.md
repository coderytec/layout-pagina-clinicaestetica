# 🚀 Landing Page Template – React + TypeScript

Template profissional de **Landing Page** desenvolvido com **React.js**, **TypeScript** e **Vite**, focado em **performance, conversão e reutilização**.

Ideal para:
- Freelancers
- Agências
- Projetos comerciais
- Criação rápida de landing pages para clientes

---

## 🧠 Objetivo do Projeto

Este projeto foi criado para servir como um **template base**, permitindo:
- Clonar o repositório
- Alterar textos, cores e links
- Publicar rapidamente em produção

Tudo com código limpo, organizado e escalável.

---

## 🛠️ Tecnologias Utilizadas

- ⚛️ React.js
- 🟦 TypeScript
- ⚡ Vite
- 🎨 CSS puro (sem libs pesadas)
- 📦 Yarn

---

## 📁 Estrutura do Projeto

```txt
src/
 ├─ components/       # Componentes reutilizáveis (Button, etc.)
 ├─ sections/         # Seções da landing page (Hero, CTA, etc.)
 ├─ pages/            # Páginas do projeto
 ├─ styles/           # Estilos globais e variáveis
 ├─ App.tsx           # Componente principal
 └─ main.tsx          # Ponto de entrada da aplicação
